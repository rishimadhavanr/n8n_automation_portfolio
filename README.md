# n8n Automation Portfolio

This repository documents real-world automation system designs built in n8n.

The focus is not individual nodes, but how workflows behave in production environments:
- handling unreliable APIs
- managing rate limits
- processing partial data
- building AI decision workflows
- creating reusable components

---

## Approach

Every project includes:

Problem → Constraints → Architecture → Workflow Logic → Failure Handling → Result

The goal is to demonstrate system thinking, not tool familiarity.
